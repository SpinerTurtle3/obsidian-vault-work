## About the Role

McKinstry's Internal Applications team builds and maintains solutions that keep our business running: custom tools, workflows, and internal platforms that fill real operational gaps across the company.

As a Senior Software Engineer on this team, you'll own feature development and ongoing maintenance across a portfolio of .NET-based web applications. You'll work across the full stack, backend APIs in C#, modern frontends in Angular and React, relational data in SQL Server, and ship work that people at McKinstry use every day. This is a hands-on engineering role with real ownership and a direct line between your work and business impact.

---
## What You'll Do

### Application Development and Feature Work

- Design and implement new features across existing internal web applications, owning work end-to-end from technical design through deployment
- Diagnose and resolve defects, performance issues, and technical debt across the application portfolio
- Participate in requirements conversations with internal stakeholders and translate business needs into clean, maintainable solutions
- Contribute to roadmap and prioritization discussions alongside the engineering manager and product partners

### Development

- Build and maintain backend services and RESTful APIs in C# across a mixed .NET environment, primarily .NET Framework with select applications in .NET Core
- Write SQL queries, stored procedures, and schema changes against SQL Server databases
- Design data models and service contracts that are clean, extensible, and documented
- Build and maintain user interfaces in both Angular and React depending on the application; work from design specs or define UX directly with stakeholders when specs don't exist
- Configure, manage, and troubleshoot application deployments through IIS
- Support CI/CD pipelines (Azure DevOps pipelines and GitHub Actions) and deployment processes
- Contribute to cloud modernization efforts as McKinstry expands its Azure footprint
- Own work front to back

### Collaboration and Documentation

- Contribute to technical design documents, runbooks, and inline code documentation
- Participate in code reviews and help raise the baseline quality of the team's work
- Partner with business stakeholders to understand operational workflows and build software that fits them
- Flag risks early and communicate blockers clearly

---
## What You Bring

### Required

- 5-10 years of professional software engineering experience in backend or full stack roles
- Hands-on experience with C#, ASP.NET Core, Classic ASP.NET, APIs, GitHub Actions, Azure DevOps
- Hands-on experience with Angular and/or React
- Strong SQL skills including complex queries, stored procedures, schema design, and performance troubleshooting
- Hands-on experience deploying and managing .NET applications in IIS
- Comfort working across a portfolio of applications with varying ages, patterns, and levels of documentation
- Ability to write clear technical documentation and communicate findings to non-technical stakeholders

### Highly Preferred

- Familiarity with Azure services: App Service, Azure SQL, Key Vault, Function Apps, Static Web Apps
- Familiarity with Azure DevOps and GitHub for work tracking, pipelines, and source control
- Experience consuming and building REST APIs with standard patterns (OAuth 2.0, JSON payloads)
- Prior work in internal tooling, enterprise IT, or similar environments where you've maintained systems you didn't build from scratch

---
## Who You Are

We're looking for someone who:

- **Takes ownership.** When you pick something up, it gets done and done right.
- **Is comfortable with ambiguity.** Existing apps have history. You ask good questions, read the code, and make reasonable calls without waiting for perfect requirements.
- **Thinks in systems.** You understand how a change in one place affects another and you account for it.
- **Communicates clearly.** You can explain a technical problem to a business user and a business problem to a technical teammate.
- **Cares about quality.** You write code others can maintain and documentation others can use.
